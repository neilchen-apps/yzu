# YZU CSE Website Redesign

元智大學資訊工程學系網站重設計（Web 程式設計期中 Project），依 `YZU_CSE_Website_Redesign_Project_Plan.html` 製作。
所有檔案放在同一層資料夾，直接用瀏覽器開啟 `index.html` 即可，不需要安裝或建置。

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 主站首頁（採用方案 A） |
| `about.html` `courses.html` `faculty.html` `research.html` `news.html` `resources.html` | 六個內容頁，涵蓋簡介、課程、師資、研究、公告、活動、資源、聯絡八類內容 |
| `plan-a.html` `plan-b.html` `plan-c.html` | A／B／C 三個首頁方案（相同內容，不同風格、配色、排版） |
| `compare.html` | 方案並排比較、360／768／1280px 預覽、截圖 |
| `design.html` | 設計說明（問題、理念、配色對比、RWD、互動規格、測試、來源與 AI） |
| `style.css` | 共用樣式，全部顏色／字級／間距用 CSS 變數管理 |
| `main.js` | 漸進強化：主題切換、手機選單、搜尋篩選、月曆、目錄定位 |
| `shot-*.png` | 截圖證據 |

> 內容來源：[元智資工官方系網](https://www.cse.yzu.edu.tw/)（查閱日期 2026-10-08），包含師資、職員、研究方向、115 學年度學士班課程、最新消息與聯絡資訊。本站為課程專題作品，非官方網站；資料為當日快照，正式資訊請以官方系網為準。
