01 / OBSERVE

問題觀察

以「資訊系網站」常見的使用情境整理三個設計問題。這些是設計假設，需要在實際系網上逐頁確認並記錄查閱日期，不憑空批評官方網站。

問題 1・查找

入口名稱無法預測內容

「更多」「其他」等名稱讓讀者猜不到點進去會看到什麼。

對應：理念 01 資訊組織

問題 2・層級

所有區塊同等醒目

公告、輪播、連結區塊都用強烈樣式，第一眼不知道從哪裡開始。

對應：理念 02 視覺層級

問題 3・裝置

手機只是把桌面縮小

寬表格撐破頁面、雙欄變得過窄，公告標題被截斷。

對應：理念 08 響應式

02 / CONCEPT

設計理念

核心句：讓訪客在三秒內知道「這個系在做什麼」，在三次點擊內找到課程、教師或公告。

導覽依內容主題組織，不做身分分流。八類內容合併為六個頁面：

資訊架構：八類內容 → 六個內容頁
頁面涵蓋內容類別主要版型主要互動
認識本系系所簡介、聯絡長頁敘事＋頁內目錄錨點目錄、目前段落標示
課程與學程課程學年分頁＋總表radio 學年切換、課程搜尋
師資師資卡片網格radio 領域篩選、FAQ
研究與成果研究左右分區卡片＋水平探索scroll-snap 水平卡片
消息與活動公告、活動公告優先清單＋月曆搜尋篩選、月曆換月
資源與服務資源表格＋FAQdetails FAQ

首頁閱讀順序（第一眼的三件事）

  1. 系名＋一句定位

    「從程式到系統，探索資訊科技的可能。」

  2. 常用查找入口

    課程地圖、找教師、公告、文件、FAQ，名稱直接描述目的地。

  3. 內容主題卡片

    六張一致卡片，之後才是消息、研究與學習路徑。

04 / LAYOUT & RWD

排版與 RWD

內容關係決定版型

  • 並列（研究方向、教師）→ 卡片網格
  • 時間（公告）→ 日期在左的清單
  • 先後（學習路徑）→ 編號步驟
  • 長篇（系所介紹）→ 單欄＋頁內目錄

斷點（依內容擠壓處設定）

  • ≤ 1000px：四欄卡片 → 兩欄
  • ≤ 900px：雙欄 hero、目錄 → 單欄；目錄改為可換行標籤
  • ≤ 880px：導覽收合為「選單」按鈕
  • ≤ 540px：所有卡片 → 單欄

關鍵 CSS

.grid { display: grid; gap: var(--space);
        grid-template-columns: repeat(3, minmax(0, 1fr)); }
@media (max-width: 800px) { .grid { grid-template-columns: repeat(2, minmax(0, 1fr)); } }
@media (max-width: 540px) { .grid { grid-template-columns: 1fr; } }

/* 寬表格只在自己的容器中水平捲動，整頁不溢出 */
.table-wrap { overflow-x: auto; }
table { min-width: 640px; }

修正紀錄：第一版在 360px 寬度時「認識本系」與「消息與活動」出現整頁水平捲動。原因是單欄 grid 使用 1fr，其最小寬度等於內部表格的 640px。改為 minmax(0, 1fr) 後，表格只在 .table-wrap 內捲動。

05 / INTERACTION

互動規格

規格格式：目的 → 觸發 → 狀態 → 回饋 → 返回／關閉 → 鍵盤與手機。前五項只用 HTML＋CSS；後四項為 JavaScript 漸進強化，沒有 JS 時內容仍完整可讀。

互動規格表
互動技術目的觸發／狀態／回饋返回鍵盤／手機
FAQ 展開details／summary先看問題，再選擇閱讀細節點問題；＋／－符號與「已展開／點擊展開」文字再點一次收合Tab＋Enter／Space；觸控點擊
學年切換原生 radio＋:has()一次只看一個學年，降低資訊量選中標籤變實心並加 ✓選其他學年方向鍵切換同組 radio
領域篩選原生 radio＋:has()依研究興趣縮小教師範圍同上；不支援時列出全部選「全部」方向鍵；按鈕可換行
卡片 hover／focus:hover／:focus-visible提示整張卡片可點擊上移 3px、框線變主色、陰影加深；文字始終可見—Tab 焦點同樣回饋；減少動態時取消位移
水平成果探索overflow-x＋scroll-snap有限空間保留作品序列標明「可左右捲動」；不自動播放—聚焦後方向鍵；觸控滑動
公告搜尋篩選JS縮小公告範圍即時顯示「共 N 筆，顯示 M 筆」；無結果提示「重設」按鈕表單元件皆有 label；結果數由螢幕閱讀器朗讀
月曆換月JS＋table＋錨點把日期與活動連起來顯示目前月份；第一／最後月時按鈕停用上個月／下個月手機改讀右側清單；點日期跳到清單並標示
主題切換CSS 變數＋JS提供深色閱讀選項按鈕文字顯示目前主題；記住偏好再按切回按鈕可聚焦；預設跟隨系統
手機選單JS＋aria-expanded窄螢幕節省空間「選單／關閉選單」文字；展開後焦點移到第一個連結Esc 或再按一次無 JS 時導覽直接換行顯示
